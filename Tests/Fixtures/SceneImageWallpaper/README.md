# 原生 Scene 预览验收素材

在「Scene 静态预览」中点击「选择项目文件夹…」，选择本目录 `SceneImageWallpaper`。

这是 Glimmer 自造的 MIT 许可测试素材：PNG 像素由简单几何运算生成，TEX 按已验证的静态嵌入 PNG 格式编码，不包含第三方、Workshop 或 Wallpaper Engine 内置资产。完整许可见 LICENSE.txt。

预期画面是深蓝网格背景，中央有橙色圆形、外环和两个旋转的小方块。画布 960 × 600，两个真实图像图层；依赖链为 scene → model → material → TEX 内嵌 PNG。`images/` 中保留对应原始 PNG，便于检查来源。

验收作者选项：

- 「显示几何图层」关闭后只剩网格背景。
- 「图层透明度」降至 0.25 后中央图形明显变淡。
- 「图层颜色」改为青色后，中央图形实际变为青色。
- 「素材说明」未绑定图层，应保持只读。

设置仅保存在预览的临时作用域中，不导入素材库、不修改本目录、不应用桌面或锁屏。此素材只验证已实现的静态 2D 子集，不能代表效果、脚本、动画或完整 Scene 兼容性。
